# Student Performance Data Analysis System

## Overview
This project analyzes student academic performance using Python and Google Colab. It processes student data, calculates average marks, assigns grades, performs attendance analysis, and generates visualizations to help understand student performance.

## Features
- Student dataset analysis
- Average marks calculation
- Automatic grade assignment
- Attendance analysis
- Subject-wise performance analysis
- Topper identification
- Data visualization using charts
- Performance report generation

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib

## Dataset Columns
- Student_ID
- Name
- Gender
- Age
- Maths
- Physics
- Chemistry
- English
- Computer_Science
- Attendance
- Average
- Grade

## Output
- Processed student dataset
- Performance report
- Bar charts
- Pie chart
- Attendance analysis
